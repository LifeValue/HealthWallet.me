# Contributing to HealthWallet.me

Thanks for helping improve HealthWallet.me. Bug reports, fixes, translations and documentation are all welcome.

## How to contribute

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repository and create a branch from `develop`, for example `feature/your-feature` or `fix/short-description`.
3. Follow the setup steps in the [README](README.md#development-setup), and run `flutter analyze` and `flutter test` before you push.
4. Sign off every commit (see below) and open a pull request against `develop`.
