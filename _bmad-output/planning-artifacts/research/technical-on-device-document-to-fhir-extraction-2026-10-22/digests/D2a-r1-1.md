## Notes per question

**Q1 Datasets.** The only verified, licence-clean, FHIR-native source is Synthea: Apache-2.0, FHIR R4, covers all 8 target resource types. It is US-centric, so ES/DE/RO documents would need a custom localisation and rendering layer. The Synthea Coherent set (CC BY 4.0) adds notes and images but not document scans. No public dataset was found that pairs medical document images with FHIR resources. The closest are a Kaggle set of 1,000 synthetic bills and discharge summaries with JSON (licence unverified) and the 10,000-document synthetic care-transition generator (not released, as far as seen). No multilingual medical OCR or KIE dataset was found in this run, and no MIMIC-on-FHIR check was done (budget).

**Q2 Synthetic pipelines and example counts.** The pattern of rendering structured data to images and then training is documented. A key caveat comes from the care-transition study: about 97% accuracy on synthetic data fell to about 85% on real scans, so mix in real or augmented scans. PIGEON (JMIR 2026) shows FHIR-to-synthetic-letter generation at a scale of 75k, for text only. Published example counts:
- 3K samples gave F1 > 0.98 on templated documents (arXiv 2609.15706, Sept 2026).
- 223 forms were enough to make RAPTOR+ Qwen3-VL-8B beat zero-shot Gemini on clinical referral forms (May 2026).
- About 2K rows in Unsloth's own vision example.

On this evidence, roughly 200 to 3K examples per document family is the published working range. That is a synthesis, not a single source. No distillation (large-model labelling) paper was retrieved.

**Q3 Tooling (versions as seen 2026-10-22).**
- **TRL v1.16.0:** native VLM SFT, plus LoRA/QLoRA through PEFT.
- **Unsloth:** Qwen3-VL and Gemma 3 4B SFT and GRPO, with vision layers trained by default (toggle `finetune_vision_layers=False` to freeze). MedGemma is not explicitly listed. MedGemma is built on Gemma 3, so Gemma 3 support probably covers it, but that is my unverified belief.
- **LLaMA-Factory:** Qwen3-VL 2B/4B, Qwen3.5, Gemma 3/3n, QLoRA at 2–8 bit, no native GRPO.
- **MLX-VLM:** LoRA/QLoRA/DoRA plus GRPO on Apple Silicon. Its README example model is Qwen2.5-VL-3B.
- **Google:** an official MedGemma LoRA notebook and an RL notebook, with decoder-only or decoder-plus-encoder tuning.
- **Axolotl and PEFT release notes** were not checked.

**Q4 Cost and before/after.** No source in this run reported measured GPU-hours for a 2–4B VLM LoRA run on a few thousand documents. The cost evidence is indirect:
- LLaMA-Factory's VRAM table: 7B 4-bit QLoRA at about 6 GB, 16-bit LoRA at about 16 GB.
- Marketplace RTX 4090 pricing: about $0.5–0.6/h.

So a run on one consumer-class GPU is plausible, at an unverified few-dollars-to-tens-of-dollars scale. The before/after evidence is good and recent (rows 24–28). Fine-tuning helps small models most on narrow schemas, and it activates field grounding in Qwen3-VL-2B/4B. RL for structured extraction is supported by tooling: Unsloth GRPO/GSPO, MLX-VLM GRPO, the MedGemma RL notebook, EasyR1. No document-to-FHIR RL paper with numbers was retrieved.

**Q5 Privacy.** Every tool covered here runs locally (TRL, Unsloth, LLaMA-Factory, MLX-VLM), so on-prem training is feasible. For de-identification, retrieved open-source tools target DICOM and burned-in radiology text. Nothing retrieved is specific to scanned lab reports or prescriptions in ES/DE/RO. Text de-identification tools (Presidio, Philter, etc.) were not checked in this run.

## Leads worth chasing
- Full text of arXiv 2609.15706: model list, LoRA settings, GPU time, learning curve versus number of samples.
- Full text of arXiv 2605.25956 (RAPTOR+): Qwen3-VL-2B/4B fine-tuned numbers, LoRA config, hardware.
- The HAI-DEF terms of use text, to settle whether MedGemma can be used commercially.
- The MedGemma `fine_tune_with_hugging_face.ipynb` notebook: which modules it freezes, GPU used, runtime.
- The JMIR PIGEON paper (e92413): generator, Synthea use, licence, language (fetch failed).
- The Unsloth Gemma 3n/MedGemma pages and the GitHub releases list for current version numbers.
- MLX-VLM release notes for Qwen3-VL training support.
- Synthea international modules (community forks for Germany or other European countries) and a FHIR-to-PDF rendering toolchain.
- Microsoft Presidio Image Redactor, and multilingual text de-identification for DE/ES/RO.
- Large-model-to-small-VLM distillation papers for KIE, and GRPO with schema-validity rewards for JSON extraction.
